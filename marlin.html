MARLIN Trident-X Challenge

Designed and programmed a team underwater robot in the MARLIN Trident-X Challenge.

About the project

Our team is building a robot for the MARLIN Trident-X Challenge. My work covers both how the robot is built and how it is controlled, and we have tested it in a pool.

What I did

  • Used design thinking to plan the robot parts
  • 3D modelled robot parts in Onshape and prepared them for 3D printing in Bambu Studio
  • Wrote about half the Python code using the MARLIN library, including joystick controls for the left and right thrusters
  • Worked with IMU and radio beacon readings
